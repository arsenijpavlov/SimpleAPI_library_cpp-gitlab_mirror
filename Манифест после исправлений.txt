
Сводный манифест возможностей библиотеки SimpleAPI


1. Архитектурная философия и стандарты

• Стандарт C++11: Полная автономность кодовой базы без требований к современным стандартам (C++14/17/20/23).
• Максимальная обратная совместимость (Legacy): Железобетонная работоспособность на старых кросс-компиляторах (проверено на GCC 4.9.4) и старых версиях системных библиотек (glibc 2.14) под архитектуры ARM (платформа OCT3500 – Octasic).
• Zero-Dependency (Self-Contained): Библиотека зависит только от pthread (для класса SocketThread). Никаких внешних тяжелых зависимостей.
• Иерархия инкапсуляции:
	• simpleapi:: — корневые прикладные классы.
	• simpleapi::utils — публичные прикладные системные утилиты.
	• simpleapi::tools — скрытые технические классы реализации (например, ElementArray), интерфейсы и хардкорный движок метапрограммирования.

2. Динамическая подсистема конфигурации (Класс Config)

• Управление типами (ValueType): Поддерживает примитивы (long double, bool, std::string, const char*), пустые типы (ValueType::eNull) и контейнеры (ValueType::eJson, ValueType::eArray).
• Свободная двусторонняя конвертация: JSON и INI свободно конвертируются друг в друга внутри одного объекта Config через toString(). Запланировано добавление XML и YAML.
• Отказоустойчивый парсинг: При возникновении ошибки успешно прочитанные значения не обнуляются. Метод error() сигнализирует о сбое, а getError() возвращает строку описания ошибки.

Специфика реализации JSON (RFC 8259):

• Поблажки парсера: Допускается отсутствие запятых (перенос строки эквивалентен разделителю). Кавычки обязательны, только если строка содержит несколько слов. Автоматическая сортировка ключей отсутствует.

Специфика реализации INI:

• Автовыведение типов: Самостоятельно распознает в значениях числа, bool, JSON, массивы или обычные строки (кавычки для строк необязательны). Поддерживает null-элементы для ключей с пустым значением.
• Поддержка многострочности: Строка продолжается, если не закрыта кавычка, строка оканчивается на \ или следующая начинается с пробела/табуляции.
• Дублирование ключей: Одинаковые ключи в рамках одной группы автоматически склеиваются в массив (ValueType::eArray).
• Иерархия: Поддерживается большая вложенность ключей через слэш / и \.

3. Подсистема сохранения комментариев (CommentDesign)

Round-trip сохранение структуры файлов конфигурации при программной перезаписи.
• Префиксные комментарии: Блоки текста ДО значения. Одиночные строки склеиваются в один многострочный блок.
• Суффиксные комментарии: Компактный текст ПОСЛЕ значения до переноса строки. При записи библиотека пытается уложить его в одну строку.
• Кастомизация маркеров: Возможность через std::array задать любые символы начала однострочных (1-2 знака) и многострочных (1-3 знака) комментариев.
• Автоформатирование: Ограничение максимальной ширины строки многострочного комментария (opt_multiline_column_size) с автопереносом и отрисовка декоративных рамок (opt_multiline_border).

4. Статическая конфигурация (Static Config на базе XY-Macro)

Декларативное описание структур через макросы для обеспечения строгой типизации и автокомплита в IDE.
• Поддержка типов STL: Совместимость с контейнерами (std::vector, list, set, map, unordered_map, deque, array, bitset, stack, queue, pair).
• Поля simpleapi::Optional<T>: Автоматически порождают в файле пару ключей <key> и <key>_optional.
• Автогенерация Enum (SAPI_REGISTER_ENUM): Создает строго типизированный enum class. Генерирует методы ToString(), FromString() (с фолбеком в _UNDEFINED_STATE_) и EnumPossibleVariants().
• Автогенерация структур (SAPI_REGISTER_CONFIG): Генерирует методы loadConfig(const Config&) и saveConfig(). Поля Y объявляются внутри структуры, но игнорируются динамическим конфигом.
• Декларативная лямбда-валидация: Позволяет зашивать анонимные функции валидации прямо в макрос объявления поля.
• Интроспекция имени поля: Поддерживаются двухпараметрические лямбды вида [](const type& val, const std::string& key_name) -> bool, где второй параметр при вызове автоматически заполняется именем текущего поля, позволяя логировать ошибки без хардкода.

5. Собственные высокоуровневые примитивы памяти (Аналоги STL)

• simpleapi::Optional<T>: Легковесный контейнер. Метод .unset() сбрасывает статус валидности, но не затирает внутреннее значение, позволяя считывать старые неактуальные данные для вывода в логи ошибок.
• simpleapi::Variant<Types...>: Типобезопасный tagged union на вариативных шаблонах. Вычисляет размер и выравнивание на этапе компиляции (alignas), выделяет плоский массив байт во избежание фрагментации кучи. Защищен проверкой is_contains_duplicate. Доступен сверхбыстрый .get<T>() (на reinterpret_cast) и безопасный .get_if<T>().
• simpleapi::Visit(variant, lambdas...): Паттерн-матчинг для Variant. Список лямбд/функций может содержать дублирующие включения (не ломает компиляцию, сопоставляется своя лямбда под каждый уникальный подтип).

6. Низкоуровневая подсистема утилит (simpleapi::utils)

Библиотека включает набор вспомогательных инструментов для работы со строками, файловой системой, контрольными суммами и логированием:
• Обработка текста и данных: Подсчет символов в UTF-8 с игнорированием ANSI/VT100 escape-последовательностей (GetStringCharCount), HEX-конвертеры для бинарных дампов (ToHexString, FromHexString), а также продвинутый сплиттинг строк (SplitString, SplitToColumns).
• Файловая система и валидация: Рекурсивный поиск файлов через POSIX API по маскам и регулярным выражениям (GetAllFilesByMask), строковые валидаторы чисел (IsStringOfFloatNumber, IsStringOfIntNumber, IsStringOfUIntNumber), а также проверка контрольных сумм CRC (8, 16, 32).
• Специализированные компоненты: Рантайм-трекер координат парсера ParserSymbolCounter, гетерогенный контейнер OnlySizetOrString для навигации по вложенным структурам, а также модуль LoggerSettings с поддержкой ANSI-раскраски вывода.

7. Движок статической инспекции (simpleapi::tools)

Набор метапрограммируемых шаблонов и автоматов для компил-тайм анализа типов и структур:
• Интроспекция и контракты: Проверка наличия методов загрузки через SFINAE (is_config_struct<T>), классификаторы STL-контейнеров и диспетчер валидаторов ExecuteValidator.
• Парсинг и автоматы: Линейный автомат Stacker для контроля вложенности скобок и строковых литералов.
• Работа со списками типов и Callable: Компил-тайм калькуляторы размеров и выравнивания (max_size_of_type, max_align_of_type), итераторы и мапперы типов, а также анализатор сигнатур функций и лямбд (lambda_settings).

8. Сетевая подсистема (SimpleAPI Network)

Полноценный сетевой стек с упором на надежность и асинхронность:
• Низкоуровневые примитивы: Обёртки над POSIX UDP-сокетами (UDPSocket) и структура IpPort для автоматического парсинга адресов.
• Мультиплексирование: Класс SocketThread для вынесения сетевого взаимодействия в отдельный поток pthread с поддержкой обслуживания множества сокетов одновременно.
• Reliability Layer (Протокол v1): Автоматическая фрагментация и дефрагментация сообщений, контроль сессии с пингами и таймаутами (setInactivityTimer), а также проверка целостности данных через CRC.
• Колбэки: Широкий набор событийных обработчиков для соединений, сырых пакетов, автоматического парсинга JSON-сообщений (setRecvJsonCallback) и маршрутизации логов.
