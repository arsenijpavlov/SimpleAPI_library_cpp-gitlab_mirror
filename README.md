# SimpleAPI library

Проект предоставляет инструменты для работы с JSON, INI, XML(TODO) и YAML(TODO) с добавлением возможности указания пользовательских комментариев внутри файлов конфигурации. А также некоторые инструменты для быстрого развёртывания UDP сокетных соединений с возможностью фрагментации сообщений.

Ознакомиться более подробно с проектом можно прочитав [документацию](doc)
