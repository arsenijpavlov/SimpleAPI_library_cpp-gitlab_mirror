SimpleAPI v0.1.0 "Logger functions" 04.01.2025

1) Реализован функционал для работы с JSON (класс Json)
2) Реализован функционал для работы с INI (тоже в рамках класса Json)
3) Добавлены функции для удобства создания логов, в том числе с цветным выводом
4) Реализован функционал модуля Network
    - обёртка над POSIX UDP сокетом (отправка, чтение, чтение по таймауту)
    - добавлен класс SocketThread для автоматизации отправки и приёма сообщений, пользователю остаётся только настроить callback-функции
    - в рамках SocketThread реализованы фрагментация пакетов при отправке, дефрагментация при приёме, переотправка недошёдших фрагментов
    - реализвана проверка целостности пакета методом накопления ошибки (ненадёжно)
Рекомендация: Network SimpleAPI в этой версии следует использовать исключительно в рамках локальной сети
