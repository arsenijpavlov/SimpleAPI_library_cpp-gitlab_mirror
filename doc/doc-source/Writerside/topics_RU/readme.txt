Логика поиска путей: 
- структура становится вложенной для FILE.md если существует одноимённая директория FILE, внутри которой есть другие документы .md

ВАЖНО: в целях исключения ошибок работы Writerside, все пробелы в именах файлов будут заменены на дефис (-)

```
FILE.md
FILE
|-- INNER_FILE.md
```

даст итоговую структуру документов:
<toc-element topic="FILE.md">
	<toc-element topic="INNER_FILE.md"/>
</toc-element>

Writeside:
- считает за ошибку дубликаты .md по названию файла
- игнорирует уровни вложенности дальше второго
- не выставляет номера страниц для самостоятельных элементов первого уровня, если у них нет вложенностей (PDF)
