# 9. Аналоги `std::variant<T...>` и `std::visit()`

Стандарт С++17 предоставил инструментарий для выполнения кода над переменной в зависимости от её текущего типа, при этом
тип может оказаться любым из указанных на этапе компиляции, — это класс `std::variant<T...>` и функция `std::visit()`.

Библиотека SimpleAPI привносит эти удобные механизмы в кодовую базу на основе C++11. Они представлены элементами
`simpleapi::Variant<T...>` и `simpleapi::Visit()` соответственно.


## Класс `simpleapi::Variant<T...>`
Данный класс представляет собой мультикласс, внутри которого может находиться значение любого из указанных при
объявлении типов. Он чем-то напоминает структуру union, но при этом во время выполнения кода можно узнать какого типа
значение сейчас находится в объекте этого класса.

`simpleapi::Variant<T...>` имеет механизмы расчёта выравнивания по максимальному значению выравнивания памяти из всего
списка типов `T...`. Также объект такого класса всегда занимает объём памяти, необходимый самому тяжёлому из подтипов.
Если тип `T` обращается к куче самостоятельно (например, `std::string`), то `simpleapi::Variant<T...>` никак эти
механизмы не изменяет.

Реализованы методы для получения значения для определённого подтипа `.get<T>()`, но пользователь библиотеки должен сам
следить за тем, что данный конкретный тип `T` сейчас действительно является текущим для `simpleapi::Variant<T...>`. В
случае, если вызываемый тип не совпадает - получаем UB (Undefined Behavior), т.к. вызов происходит обычным
`reinterpret_cast<T>` в целях экономии процессорного времени.

Дополнительно реализованы методы с проверкой забираемого типа - в случае, если тип заполнен, то метод `.get_if<T>()`
вернёт указатель на данные типа `T`.

Инициализация по умолчанию объекта `simpleapi::Variant<T...>` подразумевает вызов конструктора по умолчанию для типа,
находящегося первым в списке `T...`. Если не передавать в конструктор `simpleapi::Variant<T...>` сразу объект нужного
типа, то компилятор сам передаст аргументы для вызова конструктора соответствующего типа.

Класс `simpleapi::Variant<T...>` имеет механизм защиты от перезаписи значения для типа, который имеет приписку `const`
при описании списка типов `T...`. Однако типы `const char*` и `const wchar*` имеет исключение из данного правила -
константность указателя (`const char*`) запрещает менять данные по указателю, но не запрещает изменить сам указатель.

Предусмотрен метод `.emplace(args...)` для вызова конструктора внутреннего объекта `simpleapi::Variant<T...>`
пользователем напрямую, без лишних аллокаций и перемещений аргументов.

Присвоение значения того же типа переменной `simpleapi::Variant<T...>` не перевыделяет память для объекта `T`, а сразу
присваивает внутреннему полю новое значение.

Класс `simpleapi::Variant<T...>` имеет поддержку в подсистеме SimpleAPI Static Config. Подтипами класса могут быть любые
из поддерживаемых Static Config типов.


## Функция `simpleapi::Visit()`
Функция `simpleapi::Visit()` является функцией-спутником `simpleapi::Variant<T...>` и повторяет поведение своего аналога
из стандарта C++17, но имеет свои отличия. Например, реализация SimpleAPI не предусматривает работу с аргументом 
`overloaded`. То есть нельзя передать структуру с перегруженными `operator()` под каждый из типов
`simpleapi::Variant<T...>`.

Вызов функции имеет следующий вид:
```c++
simpleapi::Visit(variant_object, args...);
```
, где `args...` представляет собой независимый друг от друга список лямбд, указателей на лямбды, указателей на свободные
функции и т.д.

Можно передать сколь угодно большой список аргументов - библиотека это предусматривает, но обязаны быть
предоставлены реализации под каждый из подтипов `simpleapi::Variant<T...>`. В ином случае библиотека сообщит об ошибке
времени компиляции. Порядок описания функций никак не зависит от порядка указания подтипов `simpleapi::Variant<T...>`.

Также список функций/лямбд обязан иметь один и тот же возвращаемый тип. Если пользователь забывает об этом правиле,
библиотека напомнит об этом ошибкой компиляции с описанием проблемы.

## Пример использования
```c++
#include <iostream>
#include "SimpleAPI.h"

bool func_int(const int& i)
{
    std::cout << "is integer: " << std::to_string(i) << std::endl;
    return i > 0;
}

int main()
{
    using namespace simpleapi;
    auto lambda_nullptr = [](std::nullptr_t) -> bool
    {
        std::cout << "is null" << std::endl;
        return false;
    };

    Variant<int, std::nullptr_t, bool> var(false);
    bool result = Visit(var,
                        func_int,
                        lambda_nullptr,
                        [](bool b) -> bool
                        {
                            std::cout << "is bool: " << (b ? "true" : "false") << std::endl;
                            return b;
                        }
                        );
    
    return result;
}
```

При выполнении данного кода получим строку `is bool: false`, причём переменная *result* будет содержать значение `false`.
