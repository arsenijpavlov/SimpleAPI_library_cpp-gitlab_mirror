# Инструкция по компиляции документации:

Для создания документации в конечном виде следует использовать либо любую IDE от JetBrains с плагином WriterSide, либо их официальный docker-образ для автоматизации этого процесса

# Компиляция через графическую IDE
Проект Writerside позволяет сгенерировать документацию в WEB или PDF формате через настройки сборки.
Перед началом сборки следует выполнить скрипт `collect_all_md_structure.sh` с параметром выбранного языка (ru/en и т.д.) для автоматической интеграции всех Markdown-документов в итоговую документацию.

```bash
./collect_all_md_structure.sh ru
```

После этого можно нажать на треугольник запуска процесса сборки документации в выбранный формат.
