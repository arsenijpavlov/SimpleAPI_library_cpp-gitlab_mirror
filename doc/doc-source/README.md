# Инструкция по компиляции документации:

Для создания документации в конечном виде следует использовать либо любую IDE от JetBrains с плагином WriterSide, либо их официальный docker-образ для автоматизации этого процесса

# Компиляция через графическую IDE
(Показательно, но неэффективно)

Проект Writerside позволяет сгенерировать документацию в WEB или PDF формате через настройки сборки.
Перед началом сборки следует выполнить скрипт `collect_all_md_structure.sh` с параметром выбранного языка (ru/en и т.д.) для автоматической интеграции всех Markdown-документов в итоговую документацию.

```bash
./collect_all_md_structure.sh ru
```

Далее нужно зайти в параметры сборки и выбрать новое имя инстанса (на основе имени файла `SimpleAPI_docs_*.tree`).
И только после этого можно нажать на треугольник запуска процесса сборки документации в выбранный формат.

# Компиляция через docker-образ

## Установка образа

Установить Docker в систему:
```bash
sudo apt install docker.io
```

(При необходимости) Изменить путь хранения образов Docker и их данных можно так:
```bash
sudo systemctl stop docker.socket
sudo systemctl stop docker
sudo echo -e "{\n\t"data-root": "<путь до конечной директории>"\n}" > "/etc/docker/daemon.json"
sudo systemctl daemon-reload
sudo systemctl start docker
``` 

```bash
docker create --name writerside_temp jetbrains/writerside-builder:latest
```

## Извлечение инструмента из docker-образа

Для удобства использования следует достать CLI инструмент Writerside из docker-образа и сделать привязку его к пути "/opt/Writerside"
```bash
sudo docker cp writerside_temp:/opt/builder <путь до конечной директории хранения>/Writerside

# сбросить необходимость прав root
cd <путь до конечной директории хранения>/WritersideCLI
sudo chown -R ${USER} .
# вернуть права на запуск после извлечения инструмента (при необходимости)
find . -name "*.sh" chmod +x {} \;
chmod +x jre/bin/java

# создать ссылку в /opt/
sudo ln -sf "<путь до конечной директории хранения>/WritersideCLI" "/opt/WritersideCLI"

# установить пакет Xvfb для источника виртуального монитора
sudo apt install xvfb
```

С этого момента на вашем компьютере подготовлен интструментарий для автоматизации сборок документации.
